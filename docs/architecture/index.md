## Design Principles

1. **Documentation as code** — all docs live alongside source code and are reviewed via pull requests.
2. **Service ownership** — every service has a defined owner visible in the Backstage catalog.
3. **Automate everything** — manual processes should be captured as runbooks and eventually automated.

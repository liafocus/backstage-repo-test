# Runbooks

Runbooks document operational procedures for common tasks and incident scenarios.

## Available Runbooks

| Runbook | When to Use |
|---------|------------|
| [Incident Response](incident-response.md) | Production incident detected |

## Writing a Runbook

A good runbook should include:

1. **When to use** — what triggers this procedure
2. **Prerequisites** — access, tools, or permissions needed
3. **Steps** — numbered, concrete actions
4. **Verification** — how to confirm the issue is resolved
5. **Escalation** — who to contact if the steps don't work
